# OpenAI Agents SDK 三臂 v2：校准预算与对称触发

批次 `deepseek-runner-3x3-v2cal`。3 个合成场景 × 3 臂 × 1 次，共 9/9 成功。模型 `deepseek-v4-flash`；协议见 `integrations/openai_agents/PILOT_PROTOCOL_3ARM_V2.md`。数据来自本目录 `manifest.json`、`report.json`、`method_summary.csv` 和 `scenario_paired.csv`。

## 冻结改动

预算以供应商输入 token 声明：soft 1200、hard 3000、target 900；按本宿主实测 provider/estimated = 0.368 换算为估算单位 3261、8152、2446。`symmetric_budget` 使插件臂与原生摘要臂均只在越过软阈值时行动；`always` 才复现 v1 的插件触发方式。三臂各 3 个场景，均只有 1 次重复。

## 结果

| 臂 | 任务成功 | 配对输入节省 | 含该臂辅助调用的总 token 节省 | 峰值输入节省 | 压缩/摘要事件 |
|---|---:|---:|---:|---:|---:|
| 无压缩 | 3/3 | — | — | — | 0 |
| 插件 `pruner_v1` | 3/3 | **+54.68%** | **+53.44%** | +53.51% | 7 次视图压缩，0 次摘要请求 |
| 原生 `native_summary` | 3/3 | +30.25% | **−29.00%** | +29.01% | 7 次摘要请求 |

插件逐场景配对输入节省为 +57.23%、+52.60%、+54.22%，均为正。原生臂的模型输入确实下降，但 7 次摘要另消耗 5,372 输入、725 输出 token；计入自身开销后总 token 反而增加。三臂任务、答案、工具和结构安全检查均 100%，重试与恢复失败均为 0。

与 v1 同任务批次并列：插件输入 +57.93% → +54.68%，含开销 +55.51% → +53.44%；原生输入 +43.85% → +30.25%，含开销 −42.13% → −29.00%。v2 同时改变预算换算与触发策略，不能把差值单独归因于其中一项；独立模型轨迹也不是逐请求反事实。

这些是合成工具调用场景、单模型、每场景单重复的结果。三场景的 bootstrap 区间不代表跨 Agent 或生产任务的稳定收益。`estimated_cost_total=0` 是价格未映射，不能解释为免费；实际金额应按供应商账单核对。
