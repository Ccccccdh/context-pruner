# CrewAI r21：r20 同合同开发批的累计预算重跑

r20 `crewai-r20-orderfree-3arm-01` 在 7/36 行处中断。其 `--resume` 新建零起点请求预算，且原 batch 没有逐调用持久槽；因此旧批**原样保留为不完整证据**，不续跑、不改 manifest、不作收益结论。

r21 只修执行基础设施：沿用 r20 的四项开发任务、三臂、三重复、顺序无关覆盖合同、严格/语义 judge、插件机制、无 guard 配置、模型及 390 次请求硬顶。新 ID 为 `crewai-r21-orderfree-3arm-cumulative-01`，与 r20 一样只属于**开发证据**，不能称留出确认。旧 r20 已暴露首个任务的部分轨迹，r21 不可当盲测。

唯一新增行为是每次 `RequestBudget.consume()` 在供应商调用前将全局请求槽写入 `request-slots.jsonl` 并 `fsync`。恢复前独立检查冻结 manifest、记录行、槽序列：累计槽数必须等于已完成行的 `api_request_attempts` 之和，且未越 390；不一致则拒绝恢复并保留部分批。整批审计须在 r20 冻结判据的基础上额外核槽序列、累计尝试数、完整成本。摘要、失败尝试、补救均消耗同一槽；缓存只改变美元、不改变完整 token。

付费前门：新 runner/审计器/本协议写一次冻结；离线测试验证正常恢复、未记录尝试、重复槽、冻结漂移、截断行拒绝；新 ID mock 完整网格和独立审计通过。若网络或自动审批失败，保存失败批，不改旧目录。质量或审计任一门失败立即停止扩样；若小试通过，也需独立新任务确认。
