## 实验是什么

使用真实 Agents SDK Runner.run_sync、OpenAIChatCompletionsModel 和六个函数工具。模型自主调查规则、写研究摘要、关闭阶段、读取后续工作单、生成JSON产物并公开检查；没有固定调用次数或强制缺失。A0保留完整历史，A1同阶段归档但关闭恢复，A2同归档且允许选择性恢复、TTL2。模型 deepseek-flash，temperature0、thinking disabled、最多输出2048token，自动HTTP/客户端/SDK重试与 tracing 关闭。

任务是**合成工作区开发任务**，不是Django修复或未见正式评测。固定候选顺序为 dispatch_routes、sensor_windows、retention_policy；三个均通过真实离线验收对照（current reference PASS、empty FAIL、obsolete-version FAIL），按顺序纳入前两个。当前与历史规则版本具有不同来源哈希和计算结果。所有任务源与验收代码本地冻结；工具只能访问固定合成源及生成产物，不能读项目代码或任意文件。

独立验收在模型停止后从当前规则计算预期行，并核对当前来源版本和原文规则引用；预期答案不作为自然模型工具反馈。公开检查器仅做来源与浅层结构检查，不反馈独立预期行。模型保留摘要和自然重读均允许，A1无需被迫失败。
