## 门控与审计边界

- 零 API：27 格 mock 网格完整，三任务三臂严格/语义全部通过；四项审计负控制通过。零 API 演练曾发现证书任务决定词 `RELEASE` 与事实字段 `release_ready` 冲突；在最终冻结及任何付费请求前改为 `DEPLOY`，随后重新完成全网格门控。
- 付费审计从逐调用记录的角色和宿主执行工具字段重建第一角色来源覆盖，并与 runner 轨迹核对；逐调用 Agent/摘要 token、请求槽和总量一致。三个任务的质量门与成本门逐任务均通过。
- 三任务仍共享两角色、四来源、合成历史填充的任务形状；因此只能说明 r25 守卫在**这个任务族的新内容和一个负向决定**上复现。尚未验证自然任务、多样工作流或其他 Agent。`can_be_quoted_as_saving=false`，不得把 25.28% 写成普遍有效结论。
