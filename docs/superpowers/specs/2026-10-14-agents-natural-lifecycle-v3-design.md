# Natural lifecycle v3 design

User authorized proceeding in roadmap order. This architectural addition answers stage3 only first; stage4/5 remain conditional. Existing workspace and untracked tooling retained; opt-in new files, no Git commit. Earlier stop request was revoked by the explicit continuation.

Three deterministic synthetic workspace development candidates: dispatch routing, sensor transformation, retention scheduling. They are a new task family, not SWE-bench or evidence of Django repair efficacy. Select first two passing offline admission in that order, no outcome-based replacements. Each has versioned early rules, obsolete same-path evidence, later work orders and independently computed expected artifacts. Baseline, reference and wrong-version controls must distinguish success. Early summaries and source rereads are permitted; do not force forgetting or successful recovery.

Three arms share prompt/tools/materials: A0 full history; A1 stage archive without recovery; A2 archive with recovery TTL2. Memory archive backend. Six natural SDK tool-using samples, one repeat; rotated arm order by task. At most24 model HTTP requests per sample,144 per batch,USD2 nonrefundable conservative all-miss peak reservations,32000 transmitted bytes per request,2048 output tokens. Model deepseek-flash,temperature0,thinking disabled,tracing disabled,all automatic retries disabled. No resume or automatic new paid batch after infrastructure failure. Provider usage fields unavailable remain unknown. Samples terminating at SDK max turns are ordinary task failures; source/accounting/safety failures stop batch.

Reuse immutable v1 lifecycle adapter and v2 audit/client. New scoped model-input filter runs adapter, persists authoritative and visible input, binds each HTTP attempt to that input and serial turn, enforces24-request limit. Freeze task definitions,prompt,tool schemas,source hashes,dependency versions,prices and limits before paid request. Converted initial A0/A2 inputs must match. Every boundary records tool pairing, archived/recovered current evidence and obsolete evidence exposure; recovery delivery requires exact original function group present in SDK visible input and HTTP converted message content. TTL removal is reported only if an actual later boundary proves it, otherwise censored, never forced extra paid calls.

Workspace is limited to generated fixture files and artifact.json. Tool reads current or historical source through trusted receipt with host SHA; close_research only after current read. Model writes summary, closes research, obtains work order and creates JSON artifact. Public checker validates schema and provenance, never returns hidden expected rows. Missing citation yields host missing_evidence; model report_missing independently records autonomous signal. Unknown entity is a valid negative recovery signal. Natural rereads are counted separately. Independent evaluator derives rows from frozen current contract after model stops; no reference answer is sent to model.

Opportunity metrics: early current group actually archived before later dependency; signal origin host/model; no opportunity, no trigger, missed recovery, wrong version, original restored-but-unused, successful dependency, natural reread, TTL observed/censored.
