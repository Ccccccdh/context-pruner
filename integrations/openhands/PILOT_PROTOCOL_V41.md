# v41 OpenHands 开发候选（零 API 预检协议）

v40 是新实例 `django__django-16315` 的独立小试，已审计结束。
本版查看其结果后复用同一任务，属于**开发复验**；今后即使本任务
数字改善，也不能当成新的外部泛化证据。

固定公开源码、宿主正负测试门控、模型、三组、36/16 请求上限、
20k/16k/28k 压缩阈值、24+2+10 请求分段均沿用 v40。计划比较
无压缩、原生摘要与插件三组，各 1 次，旧结果不覆盖。

有意改变两处，必须分开解释：

1. 三组共用编辑范围预检。编辑只允许任务指定的两个源码文件；
   对其它文件的编辑请求在重试护栏之前返回明确的只读提示。读取
   仍允许在公开研究范围内进行。该共同工具改动不能归功于插件。
2. 插件专属压缩记忆增加短的宿主编辑合同，内容只重复 Agent 已
   获得的允许编辑范围；不包含宿主目标测试或参考补丁。v40 的
   4 次压缩中 `task_contract_chars` 全为 0，而 v41 同轨迹回放
   每次为 109。用户消息本身原已受保护，因此此改动的行为收益
   仍是待验证假设。

零 API 机制门控：合成 SDK 视图结构与源视图不变测试通过；v40
冻结轨迹 35 次请求的本地回放中，v36/v41 都有 4 次安全压缩，
v41 的派生视图累计多约 176 个估计 token。固定后续动作的回放
只能证明范围保留与预算安全，不能预测修复成功率或供应商用量。

任何付费开发复验仍须按具体运行范围另行授权。若此版通过开发
门控，再选从未用于调参的新任务做独立验证；三组成功率、全配对
输入和峰值按预定口径完整报告，不筛除失败与未压缩样本。
