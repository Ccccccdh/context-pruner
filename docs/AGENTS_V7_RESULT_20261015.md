## 费用与解释边界

78次请求均有完整usage，总估价0.027987264—0.055974528美元。保守最高价全未命中预留0.5367495美元，未触及2美元上限；预留不是账单支出。单价按当日核对的[DeepSeek官方价格](https://api-docs.deepseek.com/quick_start/pricing/)：每百万token非高峰命中/未命中/输出0.003/0.15/0.60，高峰0.006/0.30/1.20。这里报告双价估计范围，没有做账户账单核销。

A2汇总输入比A0少35.4%，usage估价低25.4%；但比A1贵15.7%，四个实例中两低两高。模型轨迹、摘要和服务端缓存表现不同，不能把这些价差归因于宿主归档。仅替换后端仍返回同样的整份JSON，不会自动节省模型token。

自然队列中A2正文构造调用为8、A1为16，差值同时包含读取次数变化和归档命中；不能把全部差值解释成归档收益。已验证的四次命中确实绕过当前源正文构造，但来源校验仍执行。当前正文从任务内存序列化，不能据此声称省掉了昂贵文件加载或实测降低了延迟。本轮没有测量缓存加速效果。

四实例各一次，只支持开发级描述；质量非劣、稳定费用节省、对未见任务族的泛化、正式实验准入均未确认。
