## 3. 不能据此宣称的内容（重要）

1. **n=1，单任务单次。** 两组的 65% 与 41% 差距本身说明**方差很大**，不能外推为稳定收益，
   也不能据此宣布达到验收目标（净输入或成本降 ≥30%）。
2. **Pruner 臂与基线不同源。** 无压缩臂首阶段 26 次后动用 **7 次纠错**，Pruner 臂 21 次、
   纠错 0 次。两者轨迹长度与纠错次数不同，节省率包含 Agent 行为差异，
   不能把差异全部归因于压缩算法。
3. **原生摘要的压缩事件为 0**：该臂 15 次请求内从未触发摘要，故其相对基线的
   −65.23% 主要来自**更短的轨迹**，而不是摘要机制本身。
4. 本实例只有 1 个可编辑文件，**跨模块复杂性弱于** v45/v46 使用的 `django-15563`（2 文件）。

## 4. 本轮观察到的环境限制（如实记录）

- **临时目录重定向在本轮未生效。** 报错路径为项目根下 `code\oh_editor_history_*`，说明
  SDK 在包装器设置 `TEMP/TMP/TMPDIR` 之前就已解析临时目录。三组均出现
  文件编辑器历史缓存 `PermissionError`（AgentErrorEvent 计数：2 / 2 / 1），
  但三组仍全部完成并通过宿主验收。
- **`windows-compatibility.json` 的准备期错误**：该文件在准备阶段被从 v46 批次复制，
  因此最初记录了 v46 包装器路径，导致首次审计以哈希断言失败。已修正为 v47 包装器路径，
  记录中的 SHA-256 与当前文件逐字节一致；实验请求、账本、样本与宿主评测不受影响。
  详情与说明写在同目录 `windows-compatibility.json` 的 `correction_note` 字段。
