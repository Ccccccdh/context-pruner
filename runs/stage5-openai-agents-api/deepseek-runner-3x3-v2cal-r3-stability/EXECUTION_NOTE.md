# 执行语义说明：协议中的“重复”与生成器实际变体

冻结协议沿用 runner 的 `--repeats 3` 参数名和“三次重复稳定性小试”标题。实际 `build_case(scenario, repeat)` 对每一轮使用 `Aurora-API-00/01/02` 代号，并生成 `6 + repeat` 组旧合成笔记。因此 repeat 0、1、2 的输入**不相同**：除代号变化外，历史每轮增加一组 assistant/user 消息。每轮内三臂共享同一个场景变体并轮换执行顺序。

据此，9 个配对是三类场景各三个**历史变体**的配对，不是三个完全相同输入的独立随机重复。冻结协议及批次 ID 保持原样以保留事前记录；本说明在运行后澄清实际生成器语义，结果报告将 55.41% 解释为含变体的描述性配对均值。旧 v2cal 批次没有并入本批统计，之后若检验纯随机稳定性，应固定完整任务输入，仅改变独立运行编号和臂顺序，另开新批次。
