## 冻结的统计判定

统计代码、协议和全部任务在付费前冻结；审查修复均在冻结前完成。结果出来后未换检验、删实例或改变样本量。

质量：对B1和B2各使用单侧97.5% Clopper–Pearson成功率下界，以Bonferroni保护两个质量界；用B0成功率上界1形成保守差值下界，非劣界值为10个百分点。两组均48/48通过，成功率下界为0.926027215，差值下界为−0.073972785，即−7.40个百分点，均高于−10个百分点门槛。因此在该预设界值下通过质量非劣判定，不能据此声称真实失败率为0或对任意更严格界值也成立。

token与费用：以48个实例的log(B1/B0)配对比为样本，计算单侧95% Student t均值上界，再指数化为几何均值比上界；目标≤0.90。自由度47，临界值1.677926722。

实例级几何均值点估计表示总token减少24.83%、费用减少17.80%；相应上界对应至少约23.44%和12.65%的降低，均达到预设至少10%门槛。高/低费用采用同一套usage和成比例价格，不能当作两份独立证据。

主要联合结论要求两个质量非劣条件、总token和两套费用上界全部通过，现已满足。这是预设的交并检验决策；没有把各指标的区间分别包装成多重比较后仍保持总体覆盖率的独立结论。

假设：任务实例相互独立，配对log效果近似正态；质量精确二项界依赖相应独立任务试验模型。生成器、单次重复、顺序轮换、服务端缓存及提供商状态限定了解释范围。该确认不是分布无关证明，不等于对真实仓库或其他任务族已验证泛化。样本量敏感性分析在付费前保存，没有承诺联合80%功效，也没有为有利结果追加样本。

## 归档复用的独立解释

B2的96次归档命中全部经原子组、namespace、当前来源版本、回执、全文hash验证，并通过新call_id在成功请求输入中找到实际投递。B2与B1的读取次数相同，普通来源payload构造从192降为96，但720次来源完整性校验仍执行。当前正文由任务内存序列化，不能声称消除了昂贵磁盘加载或实测降低延迟。

B2相对B1累计总token少1.91%、费用估价低4.21%；48实例中27个B2费用更低。该比较是描述性次要结果，没有额外冻结的确认检验，不能将差异归因于归档后端。控制脚本中B1/B2最终输入完全等值；自然模型轨迹及缓存会造成差异。模型missing信号和原生命周期自主恢复使用均为0，宿主复用不等于模型自主恢复。

B1相对B0有36/48实例的费用更低，总token和费用同时更低也为36/48；总体确认不意味着每个实例都省钱。逐实例比值保存在paired-comparisons.json，包含B1/B0及B2/B1两种比较。
