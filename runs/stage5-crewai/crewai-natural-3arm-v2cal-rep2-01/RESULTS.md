# CrewAI v2-R2：诊断批（两层合成历史长度、三臂付费小试）

**诊断批口径**：本批定位了跨事件循环复用异步客户端的风险、4 个摘要预算槽无 usage 及未 await 关闭客户端的问题。其已记录 token 数可复算，但并非完整费用凭证；后续 r2fix 批次修复生命周期和计数后独立重跑。本批不作为“完整成本优于基线”的最终证据。

批次 `crewai-natural-3arm-v2cal-rep2-01`，2026-10-02。使用 `deepseek-v4-flash`，3 个合成任务 × 2 种历史长度 × 3 臂，共 18/18 样本完成。`repeat=0` 使用 8 条合成历史单元，`repeat=1` 使用 9 条；两层是**场景变体**，并非完全相同输入的随机重复。三臂在同一个任务×历史长度内配对。任务成功率每臂 6/6，工具、输出格式及结构安全检查均通过。

## 独立审计

`.tooling/audit_crewai_v2_r2.py` 复核退出码 0，`audit.json` 记录 `complete: true`、18 个唯一样本、运行器与任务哈希匹配、预算槽与 token 恒等式匹配、结果摘要复算一致。全局预算槽使用 **69/96**：54 个 Agent 尝试、15 个摘要槽预留；其中 11 个摘要取得 usage，**4 个预留没有 usage**。这些槽可能对应传输失败、请求前失败等，现存结果不足以判断是否抵达 HTTP 端点。三臂均无 Agent 重试和硬预算违规。审计复核了源哈希与结构化结果；冻结协议未在启动前单独保存 SHA256，也未写入 manifest，因此不能声称其**字节级**启动前哈希已验证。执行期解释勘误另见 `EXECUTION_NOTE.md`。

各臂合计输入/含**已记录**辅助调用总 token：无压缩 27,942 / 29,975；插件 24,204 / 26,154；原生摘要 27,100 / 39,699。原生摘要有些成功生成的摘要未缩短内容，已知额外调用成本已超过 Agent 输入的减少。15 次摘要槽预留均被计入 69 个全局预算槽；其中 4 次没有 token usage，所以总 token 是已记录成本的下界，不等同完整账单。没有样本因预算上限而跳过摘要或终止。

## 与 v2cal 的关系和限制

旧 v2cal 是相同三任务的 r00 单层，9/9 成功，插件输入 +12.74%、总量 +11.47%；本批 r00 为 +12.89% / +11.90%，方向与量级接近。旧批原生摘要总量 −36.03%，本批两层仍为负。两批独立运行，不能合并 n 或把差值解释为算法提升。本批修复了**原生摘要请求不计入全局请求上限**的问题，并把单样本摘要上限 16 降至 6；实测各原生样本最多 3 次，故该护栏未触发。其余任务、模型、预算和压缩触发规则沿用 v2cal。

本实验只覆盖三个简短合成工具任务、一个模型、两种相邻历史长度；不验证真实 CrewAI 长任务的成功率或跨项目稳定收益。下一步应先选更长、可复核的自然任务，冻结质量门控与请求上限，再做小规模多任务试验，而不是据此宣称通用插件已稳定。
