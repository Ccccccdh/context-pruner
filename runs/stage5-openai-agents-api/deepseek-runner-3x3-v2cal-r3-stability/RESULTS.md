# OpenAI Agents v2 校准预算三轮场景变体验证

批次 `deepseek-runner-3x3-v2cal-r3-stability`，冻结协议见 `integrations/openai_agents/PILOT_PROTOCOL_3ARM_V2_R3.md`，实际生成器语义见本目录 `EXECUTION_NOTE.md`。三类合成场景 × 三臂 × 三轮历史变体 = **27/27 完成**；9 个配对包含代号和历史长度不同的三轮变体，同一轮的三臂使用相同变体。零 API 计划、8 个单元测试和三臂门控均先于付费运行通过。实际 84 次 API 请求（硬上限 240），无重试或异常。原始 `samples.jsonl`、runner `report.json` 与独立 `audit.json` 在本目录，审计 `complete: true`、零问题、四个冻结源码哈希一致。

插件在含三轮变体的 9/9 个配对中，含开销总 token 节省均为正，范围 **+48.60% 至 +60.92%**；达到预先定义的 7/9 正收益和质量不低于无压缩门槛。这个门槛说明正收益覆盖了本批三轮历史变体，不能当作同一输入重复采样的稳定性检验。按场景的三轮变体均值分别为：单工具 +58.40%、并行工具 +55.06%、链式工具 +52.77%。原生摘要虽减少 Agent 输入，但其 21 次摘要请求另消耗 19,350 输入和 3,304 输出 token，因此 9/9 配对的含开销总量均增加（−41.61% 至 −26.51%）。三臂的工具协议、答案格式及结构检查均 9/9；插件未靠牺牲这些检查获得节省。

旧 `deepseek-runner-3x3-v2cal` 只有每场景一次（9 样本），插件含开销节省 +53.44%，本批 +55.41%；方向和量级一致。旧批与本批不合并，repeat 0 也是独立模型轨迹。新批 repeat 1/2 的合成历史更长、codename 不同，因而这不是同一输入的三次随机重复，也不是对真实复杂任务质量的检验。批次 ID 保留冻结时的 `r3-stability` 字样，但结果按场景变体验证解读。

审计从 `samples.jsonl` 独立重算 27 个唯一键、成功和结构标志、工具调用及最终答案、逐调用 usage 求和、9 个配对均值和 84 次请求账本；与 runner 报告吻合。最大单样本 6 次请求；估算输入加实际输出与摘要 token 的最大样本值为 24,260，低于协议中的 312,000 token 规划警戒线。全批三臂合计 96,141 个供应商记录 token。`estimated_cost_total=0` 是未配置价格映射，**并非免费**，金额以 DeepSeek 账单为准。

**结论范围**：在这个短、合成、任务答案易于验证的 OpenAI Agents 工具调用基准上，插件的正节省覆盖三轮历史变体，且本批未观察到质量或结构损失。+55.41% 是含变体的 9 对描述性均值，不是同一输入多次随机执行的稳定性估计。不能据此声称 OpenAI Agents 真实软件任务、长纠错任务或其它宿主普遍受益；下一阶段应加入自然多步任务并保留同样的配对质量审计。无压缩和原生摘要均在同批独立运行，模型轨迹存在随机性，配对不构成逐请求反事实。
