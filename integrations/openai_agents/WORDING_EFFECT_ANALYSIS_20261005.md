## 2. (a) 该效应是否系统性？

**机械判定：不是"普遍变长"，而是"离散度变大 + 长尾"效应。**
- 方向上不成系统：配对中位数 **0**，符号 6 正 6 负；均值被正尾拉起（+11.6），不能读成"普遍更长"。
- 离散度确实不同：基线臂长度 sd **10.3**、插件臂 sd **22.4**（约 2.2 倍）；三种任务上基线臂在三重复间
  **逐字节稳定**（v13 三臂全稳定；v14 的 `none` 三任务分别恒为 133/152/128），而**插件臂在每个任务上都不稳定**
  （xarray 出现 143 与 179 两种长度，2/3 超长）。
- 失败只在插件臂出现（3/3），且**不是确定性失败**：同一任务 `xarray_copy_dtype` 的第 3 次重复是 143 字符、通过。

## 3. (b) v13 为什么没触发？

- v13 的插件臂三重复全部 **139** 字符（比基线 145 **短 6**），即那次模型给出的措辞更紧凑；
  基线/native 三重复全部 145、**逐字节相同**，因此 v13 实质上是**一个确定性观测**，不是三次独立重复。
- 这不是"v13 的任务形状让效应无法出现"：v13 的视图/载荷与 v14 同形（三视图两轮读取、三处指针），
  指针文本长度也一样（157 字符/处，见 §4）；差别在于**该任务的答案内容本身能在 160 字符内写完**。
- 反例即 v14 的 `xarray_copy_dtype`：基线答案是 128（很宽松），插件臂却写出 179（多出一个解释性从句
  `passes data through as_compatible_data, which coerces unicode to object`）。
- 结论（描述性）：**这是"答案内容长度 + 模型措辞"的任务相关量**，本次数据无法把"任务"与"随机波动"分开
  （v13 每臂 3 次重复完全同值，v14 每任务只有 3 次且插件臂本身不稳定）。

## 4. (c) 是否存在"压缩后模型需要更多解释"的可机械观测线索？

| 线索 | 观测 | 判定 |
|---|---|---|
| 指针文本本身占位 | 每处指针 **157 字符**，每样本 3 处 → 载荷中约 471 字符的指针文本 | 指针短，且替换掉的是 3,170–9,489 字符的重复副本，载荷整体变小 |
| 被省略证据 vs `cause=` 提到的内容 | 13/13 插件样本：答案用到的词元在**基线最终可见文本**里出现的个数与在**插件最终可见文本**里出现的个数**完全相同**（`missing = []`） | **"压缩藏起了证据、逼模型多解释"不成立**：答案所需的可见信息在两侧都还在 |
| 省略量能否排序漂移 | 省略 4,755 字符 → 139/146/148；省略 3,170 → 133/136/151；省略 9,489 → 143/179/179 | **无单调关系**；最大省略量恰好漂移最大，但次大省略量为负漂移，不能据此建立因果 |

**机械判定小结**：机制侧没有可观测的"隐藏证据"迹象（token 保全 13/13），失败是**模型侧措辞长度落在长尾**
（3 条超长全部来自插件臂、且同任务另一次重复通过）。但**长尾本身与该机制相关**这一点是可观测的（插件臂离散度
是基线的 2.2 倍、且插件臂在三任务上都不稳定），因此不能写成"与机制完全无关"。

## 5. 三种去路的代价评估（**只评估，不执行**）

| 去路 | 需要多少新证据 | 能否救回已有结论 |
|---|---|---|
| **① 保持现判据不变** | 0（现状即结论） | **能——就是现状**：v12 0/1、v13 3/3、v14 7/9 与 `acceptance.met=false` 全部保持；四判据里"多任务+稳定"仍未达成 |
| **② 全新任务上预注册"事实轨为主、长度轨单独报告"的新判据** | **高**：新任务（≥3 个未用实例，三宿主均未引用）+ 新 ID + 前瞻冻结 + 新批次（每任务×3 重复×3 臂，另加获取批）；冻结里必须写明长度轨只作单独报告、不进验收，且**不得引用 v12–v14 的结果作为依据**（否则就是用旧结果调新判据） | **不能**：该新判据只适用于其自身批次；v12/v13/v14 的严格失败**不得**按新判据重判（用户明令"任何改判都不能追溯"） |
| **③ 改机制以减少措辞漂移（指针措辞/指针位置等）** | **高**：属机制变更 → 必须在**新任务**上重新走 证据门→曝光门→非零空间门→不变量门→小试（新 ID、前瞻冻结）；且需要先给出可证伪假设（例如"指针改成极短标记可降低长尾"），本次数据不足以定方向 | **不能**：机制变更后的批次是新证据；v12/v13/v14 的结果仍是旧机制的结论，不得重判也不得拿来当新机制的支撑 |

**共同约束（三条都适用）**：任何改判**不能追溯**适用于已完成的批次；不得把 Track B（27/27）写成"质量不降"；
